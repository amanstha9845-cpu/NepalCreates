# NepalCreates

Multi-page website for a fictional Nepal-based creator management agency. BIT 4th Semester Web Technology project. Built with HTML5, CSS3, and vanilla JavaScript only.

## Structure
```
NepalCreates/
├── index.html   about.html   contact.html
├── css/style.css
├── js/script.js
├── images/hero.svg  about.svg
└── README.md
```

## Run locally
1. Open the `NepalCreates` folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

## Deploy on GitHub Pages
1. Create a public repository and upload all files (keep `index.html` at the root).
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. After a minute, your site is live at `https://<username>.github.io/<repository>/`.

## Notes
- The contact form validates input in JavaScript but sends nothing (frontend demo).
- Font Awesome and Google Fonts load from CDNs, so an internet connection is needed to see icons and the Manrope font.
- NepalCreates is fictional. The email address uses the reserved `.example` domain.
